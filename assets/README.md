# Assets

## fonts/

Place Inter font files here for the best typography experience:

- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-SemiBold.ttf`
- `Inter-Bold.ttf`

Download from [rsms.me/inter](https://rsms.me/inter/) or the [Inter GitHub releases](https://github.com/rsms/inter/releases).

If these files are absent, Flet falls back to the system sans-serif font.

## icons/

Place `icon.png` (1024×1024 px) here. `flet build` uses it to generate
platform-specific app icons automatically.
